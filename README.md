# 直播脚本01

一个用于分析、生成、改写和训练直播脚本的 Codex skill。

它适合咨询型、高信任行业直播间，例如婚姻家事律师、情感咨询、教育规划、财税顾问、医美咨询、本地生活服务等。

## 能做什么

- 分析直播脚本的人群定位、留人钩子、信任机制、转化路径
- 生成咨询型直播脚本，要求像真人直播口语，不像 AI 文章
- 改写已有脚本，加入案例、互动、私信承接和合规边界
- 生成私信引导、领资料、免费咨询、灯牌、下播收口等互动话术
- 提炼短视频切片稿
- 输出直播运营训练方案
- 标记非法取证、隐私、平台敏感、绝对承诺等风险，并给出安全改写

## 安装

把整个 `livestream-script-01` skill 文件夹放到你的 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills/livestream-script-01
cp -R . ~/.codex/skills/livestream-script-01
```

如果你是从 GitHub 克隆：

```bash
git clone <your-repo-url> ~/.codex/skills/livestream-script-01
```

然后重启 Codex 或刷新 skills 列表。

## 调用示例

分析脚本：

```text
用直播脚本01分析下面这篇直播脚本：
重点看人群定位、留人话术、案例、私信转化、互动话术、合规风险和可优化点。
【粘贴脚本】
```

生成新脚本：

```text
用直播脚本01生成一篇直播脚本。
行业：婚姻家事律师
主播身份：帮助原配处理婚姻危机的律师
目标用户：发现老公出轨、不知道证据怎么找的原配
主题：没有聊天记录还能不能起诉
平台：抖音
时长：30分钟
风格：像真人直播，口语化，不要 AI 味
```

改写脚本：

```text
用直播脚本01优化这段直播脚本。
要求：更像真人直播，更强转化，加入案例、互动、私信口、领手册话术，同时规避敏感风险。
【粘贴脚本】
```

生成互动话术：

```text
用直播脚本01生成一套直播间互动转化话术：
包括私信引导、领手册、免费咨询名额、要灯牌、下播收口。
行业：婚姻家事律师
风格：口语化，不要太 AI。
```

## 合规边界

这个 skill 不用于生成非法取证、监听、跟踪、破解账号、绕过平台审核等具体操作步骤。

如果原脚本涉及敏感内容，它会保留运营分析价值，但把具体表达改成更安全的版本。
