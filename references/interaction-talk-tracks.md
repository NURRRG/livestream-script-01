# Interaction And Conversion Talk Tracks

Use this reference when generating a script, optimizing a script, or creating standalone livestream interaction prompts.

## Public Comment To DM

Purpose: move vague public questions into structured private intake.

Required elements:

- public comments are too short for case judgment
- each situation depends on stage, materials, evidence, identity, amount, and goal
- ask the user to DM a short structure
- mention assistant/intake only if the user wants a conversion workflow
- keep it natural, not like an ad

Template:

"姐妹，你这个问题在直播间没办法一句两句讲清楚。你现在是什么阶段，手里有什么材料，有没有关键记录，想解决的是钱的问题、关系的问题，还是后面怎么走的问题，这些都会影响判断。你不要只在公屏刷一句话，我没办法靠这一句话判断。你点头像进主页，后台私信，把时间线、材料、你想解决的问题说清楚。能不能做、从哪里下手，要看完这些东西再说。"

## Handbook Or Resource Claim

Purpose: convert missed or confused viewers into follows and DMs.

Use after a method section or when new viewers enter.

Template:

"刚才这个方法，刚进来的姐妹可能没听全。没关系，我已经把它整理成一份【资料名称】。直播间我只能讲方向，细节要看你自己的情况。想要的姐妹，评论区打【关键词】。点好关注之后，进主页后台私信，我让助理发给你。这个资料不是卖课，也不是让你刷礼物，是给你先把思路理清楚。"

Safer resource names:

- 材料整理清单
- 合法取证避坑手册
- 咨询前自查表
- 直播间高频问题答疑表
- 风险自查表

## Free Consultation Slots

Purpose: identify high-intent users and set boundaries.

Template:

"姐妹们，今天直播间放几个初步评估名额。这个不是闲聊，也不是单纯情绪安慰。你把情况整理清楚，我帮你看几个方向：你手里的材料有没有用，下一步卡在哪里，哪些证据还缺，值不值得继续评估。想要这个名额的，后台私信打【咨询】两个字。一定要打对关键词，不然后台不好识别。名额有限，因为一场直播我不可能把每个人的情况都看完。"

## Follow Or Fan Badge

Purpose: improve livestream relationship and distribution data without sounding like gift pressure.

Template:

"姐妹们，我直播间讲这些东西，不是卖课，不是卖货，也不是让你刷礼物。有条件的姐妹，帮我把关注点一下，或者把头上的小黄心点亮一下。这个就是帮直播间做个数据。数据好一点，平台才可能把这场推给更多正在经历这个问题的人。没有条件的不强求，你把关注点好，下次还能找到我就行。"

## Closing Recap

Purpose: summarize value and perform final conversion.

Template:

"好，姐妹们，最后几分钟了。今天我们讲了【主题1】、【主题2】、【主题3】，还有很多人最容易做错的【误区】。刚进来的姐妹，前面没听到没关系，今天讲到的内容我整理成了【资料名称】。想要资料的，点头像进主页，后台私信打【关键词】。如果你不是只想听干货，是想让我看你自己的情况，那就私信打【咨询】，把时间线、材料、你现在最想解决的问题发清楚。没点关注的姐妹，把关注点好。今天就先讲到这里。"

## Insertion Rules

- opening 3 minutes: weak follow prompt
- after first pain point: comment interaction
- after each method: handbook prompt
- after complex or case-specific issue: DM prompt
- after high-intent issue: consultation prompt
- midstream: follow/fan-badge prompt
- final 5 minutes: closing recap

## Strength Levels

Weak conversion:

- "这个要看材料。"
- "有类似情况的，先把东西整理一下。"

Medium conversion:

- "你把时间线、材料、金额、目标整理好，后台私信我。"

Strong conversion:

- "想要初步评估名额的，后台打【咨询】两个字。"
