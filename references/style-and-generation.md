# Style And Generation Rules

Use this reference when generating or heavily rewriting livestream scripts.

## Non-AI Spoken Style

The script must sound like live speech, not an article.

Use:

- "姐妹们，我跟你说句实在话。"
- "你先别急。"
- "这个地方很多人都做错。"
- "你记住这句话。"
- "我为什么反复讲这个？"
- "这个不是不能做，是不能这么做。"
- "单独看不够，要看能不能串起来。"

Avoid:

- "在当今社会"
- "本文将从以下几个方面"
- "首先、其次、最后" as an essay skeleton
- "理性看待"
- "赋能"
- "闭环"
- "高效解决方案"
- "希望大家有所收获"
- "综上所述"

## Consulting Livestream Skeleton

Use this structure for high-trust consulting scripts:

1. Live introduction
   - host identity
   - target audience
   - crisis solved
   - why today's topic matters

2. Psychological setup
   - describe the user's real state
   - remove shame or self-blame
   - regain professional control

3. Risk amplification
   - move from emotional pain to practical consequences
   - money, time, evidence, health, eligibility, opportunity, legal risk, or family risk

4. Main topic
   - name the specific question users care about
   - tell them what they will learn

5. Misconception correction
   - attack the common wrong action or wrong belief
   - then give the correct judgment rule

6. Method breakdown
   - split by scenario
   - split by "has/does not have"
   - split by stage
   - give a checklist, not vague advice

7. Case proof
   - one concrete case for each core method
   - include details such as platform, object, action, time, location, relation, result

8. Professional boundary
   - say what cannot be concluded from one fact
   - say what requires case-specific review

9. Conversion
   - DM, resource, consultation, follow, fan badge, or closing prompt

10. Summary sentence
   - repeat the core judgment in one memorable line

## Reversal Templates

Use at least one reversal in every major module:

- "很多人以为【A】，我直接告诉你，不是这么回事。真正关键的是【B】。"
- "你现在最想做的这个动作，可能恰恰是最没用的。"
- "这个东西不是不能用，是不能单独用。"
- "你以为问题卡在【A】，其实真正卡在【B】。"
- "你别上来就问能不能赢，先看你手里有没有【关键材料】。"

## Case Template

Use this when the user does not provide a full case. Label it as a sample.

"我给你举个示例场景。一个姐妹一开始不是发现【核心证据】，她是在【平台/场景】里看到一个【具体线索】。她点进去以后，又发现【第二个细节】。再往后看，还有【第三个细节】。这些东西单独看，不一定够；但如果能和【补充证据】串起来，这个方向就值得评估。"

## Repetition Rules

Livestream scripts need controlled repetition because viewers enter continuously.

- repeat the host identity every 20-30 minutes in long scripts
- repeat the core judgment after every major module
- repeat conversion prompts with different wording
- do not mechanically copy-paste the same sentence

## Script Quality Checklist

Before finalizing, check:

- Does the first 30 seconds name the audience and pain?
- Is the host identity clear?
- Does each section include a mistake, reversal, or judgment rule?
- Are there concrete cases instead of abstract claims?
- Are the core points repeated naturally?
- Are conversion prompts embedded, not bolted on?
- Are risky legal/privacy/platform instructions removed or softened?
- Can a host read it aloud without sounding like an article?
